# Character Sprites

This directory will store production-ready 2D spritesheets and animation atlases for:
- Dennis (playable protagonist)
- Manish, Sathish, and Rahul (chasers)

Planned animation states include:
- `idle`: Standing breath/stance
- `run`: Full stride dash
- `jump` / `fall`: Vertical movement frames
- `hit` / `stumble`: Obstacle collision reaction

Sprites will be introduced in subsequent asset creation and animation stages.
